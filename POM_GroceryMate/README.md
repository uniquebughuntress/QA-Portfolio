# GroceryMate – Test Automation

## Description

Automated UI tests for GroceryMate using:

- Python
- PyTest
- Selenium
- Page Object Model (POM)

## Project Structure

- pages/
- tests/
- utils/
- reports/
- screenshots/

## Installation

```bash
pip install -r requirements.txt
```

## Run Tests

```bash
pytest
```

## Generate HTML Report

```bash
pytest --html=reports/report.html
```
